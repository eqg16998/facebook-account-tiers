### 一号一 IP，Chrome 的多用户配置解决不了关联

这是最多人栽的地方。有人在一台电脑上登录 6 个 FB 账号，每个用 Chrome 的不同用户配置，觉得已经隔离了，**3 周后全军覆没**。

原因是指纹。Facebook 的风控会收集 30 多个维度的浏览器特征：操作系统、屏幕分辨率、安装的字体、时区、语言，组合起来就是一张很难伪造的数字身份证。Chrome 的多用户配置只隔离 Cookie，指纹不变，而且所有账号还走同一个 IP，平台一关联就一起封。
